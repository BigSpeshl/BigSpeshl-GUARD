# BigSpeshl-GUARD

BigSpeshl-GUARD — это автономная система защиты от DDoS-атак и обнаружения сетевых угроз на Python. Она создана как лёгкий инструмент для терминала, сфокусированный на эвристическом обнаружении, автоматической блокировке и мониторинге через CLI маршрутизатор.

## Возможности

- Анализ сетевых событий в реальном времени
- Адаптивное обнаружение шаблонов SYN flood, UDP reflection и HTTP flood
- Автоматическая блокировка IP-адресов и ограничение скорости
- Красивый интерфейс терминала с брендовым баннером BigSpeshl-GUARD
- Встроенные сценарии симуляции для проверки защитной логики

## Быстрый запуск

Требуется Python 3.9+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m bigspeshl_guard --interactive
```

## Примеры команд

```bash
python -m bigspeshl_guard --mode syn_flood --duration 12
python -m bigspeshl_guard --status
python -m bigspeshl_guard --interactive
```
