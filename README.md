# 🛡️ BigSpeshl-GUARD

> Лёгкая система обнаружения и предотвращения DDoS-атак с анализом
> входящего сетевого трафика, полностью написанная на Python.

## 📖 О проекте

**BigSpeshl-GUARD** --- это программный инструмент для мониторинга
сетевого трафика, обнаружения подозрительной активности и
автоматического реагирования на сетевые угрозы.

Проект полностью написан на **Python** и предназначен для работы из
терминала. Система анализирует сетевые события в реальном времени,
выявляет характерные признаки различных типов атак и может автоматически
применять меры защиты.

Основная задача проекта --- предоставить простой и лёгкий инструмент,
который позволяет **контролировать входящий трафик, обнаруживать
DDoS-активность и реагировать на неё в автоматическом режиме**.

## 🎯 Какие атаки анализируются

Система содержит логику обнаружения нескольких распространённых типов
сетевых атак:

### SYN Flood

Анализ большого количества TCP SYN-запросов, которые могут
использоваться для перегрузки сетевых ресурсов.

### UDP Reflection

Выявление подозрительных UDP-потоков, характерных для отражённых атак.

### HTTP Flood

Анализ большого количества HTTP-запросов с целью выявления аномальной
нагрузки.

> Конкретная эффективность обнаружения зависит от конфигурации системы,
> характера трафика и используемых порогов.

## 🧠 Обнаружение угроз

BigSpeshl-GUARD использует **эвристический подход**: система анализирует
сетевые события и ищет аномальные шаблоны поведения.

В зависимости от обнаруженной активности система может:

-   определить подозрительный источник;
-   зарегистрировать событие;
-   ограничить скорость запросов;
-   заблокировать IP-адрес;
-   вывести информацию об угрозе в терминал.

## 🚀 Установка

Клонируйте репозиторий:

``` bash
git clone <URL_РЕПОЗИТОРИЯ>
cd bigspeshl-guard
```

Создайте виртуальное окружение:

``` bash
python3 -m venv .venv
```

Активируйте его.

### Linux / macOS

``` bash
source .venv/bin/activate
```

### Windows

``` powershell
.venv\Scripts\activate
```

Установите зависимости:

``` bash
pip install -r requirements.txt
```

После установки систему можно запустить в интерактивном режиме:

``` bash
python -m bigspeshl_guard --interactive
```

## 🎮 Использование

### Интерактивный режим

``` bash
python -m bigspeshl_guard --interactive
```

Позволяет работать с системой через консольный интерфейс.

### Проверка состояния

``` bash
python -m bigspeshl_guard --status
```

### Тестирование обнаружения SYN Flood

``` bash

```
